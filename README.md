

# Python Project 04 - Student Admission System

Features:
- Add students until "done" is entered
- Store students in a list
- Retrieve students by roll number
- Validates invalid roll numbers

Concepts Used:
- Lists
- append()
- len()
- while loops
- input validation

Bugs I Fixed:
1. Stored "done" in the list.
2. String vs integer conversion issue.
3. Invalid roll numbers.
4. Roll number 0 edge case.
